## 1. Открыть папку проекта

Распакуйте проект в постоянную папку, например:

```text
C:\MegamarketControl
```

Откройте папку в Проводнике, щёлкните правой кнопкой мыши по свободному месту и
выберите **Открыть в терминале**.

Если такого пункта нет, откройте PowerShell через меню «Пуск» и перейдите в
папку проекта вручную:

```powershell
cd "C:\MegamarketControl"
```

Все следующие команды нужно выполнять из папки проекта.

## 2. Проверить файл .env

Рядом с `README.MD` должен находиться файл `.env` с готовыми настройками.
Обычно он уже входит в подготовленный комплект проекта или выдаётся отдельно
администратором.

Самостоятельно изменять этот файл не нужно. В нём находятся параметры доступа
к рабочей базе данных, поэтому не публикуйте и не отправляйте `.env`
посторонним.

Если `.env` отсутствует, запросите его у администратора. Без него приложение
не сможет запуститься.

## 3. Установить uv

Вставьте в PowerShell следующую команду:

```powershell
powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"
```

После установки закройте PowerShell и снова откройте терминал в папке проекта.
Проверьте установку:

```powershell
uv --version
```

Затем один раз подготовьте программу:

```powershell
uv sync
```

`uv` сам подготовит подходящую версию Python и установит необходимые
компоненты. Отдельно устанавливать Python обычно не требуется.

Node.js и npm для запуска программы не нужны.

## 4. Подготовить Chrome

Парсер работает через отдельное окно Google Chrome. Обычное окно Chrome для
этого не подходит.

### Настройка при первом запуске

Сначала закройте все окна Chrome. Затем выполните:

```powershell
Get-Process chrome -ErrorAction SilentlyContinue | Stop-Process -Force
```

Один раз скопируйте профиль Chrome в отдельную папку:

```powershell
robocopy "$env:LOCALAPPDATA\Google\Chrome\User Data" "$env:LOCALAPPDATA\chrome-profiles\megamarket-12" /E /R:0 /W:0 /NFL /NDL /NJH /NJS /XD Cache "Code Cache" GPUCache ShaderCache GrShaderCache "Service Worker" Crashpad
```

Копирование может занять несколько минут. Повторять его при каждом запуске не
нужно.

### Запуск рабочего окна Chrome

Эти две команды нужно выполнять перед каждым запуском парсера.

Сначала найдите установленный Chrome:

```powershell
$chrome = @("$env:ProgramFiles\Google\Chrome\Application\chrome.exe", "${env:ProgramFiles(x86)}\Google\Chrome\Application\chrome.exe", "$env:LOCALAPPDATA\Google\Chrome\Application\chrome.exe") | Where-Object { Test-Path $_ } | Select-Object -First 1
```

Затем запустите специальное окно:

```powershell
& $chrome --remote-debugging-port=51112 --user-data-dir="$env:LOCALAPPDATA\chrome-profiles\megamarket-12" --disable-blink-features=AutomationControlled --no-first-run --no-default-browser-check --lang=ru-RU --window-size=1366,768
```

Не закрывайте открывшееся окно Chrome во время работы программы.

Проверьте подключение:

```powershell
Invoke-RestMethod http://127.0.0.1:51112/json/version
```

Если PowerShell показал информацию о версии Chrome, браузер подготовлен
правильно.

## 5. Запустить приложение

Оставьте специальное окно Chrome открытым. Откройте ещё одно окно PowerShell в
папке проекта и выполните:

```powershell
uv run uvicorn megamarket.api.app:app --host 127.0.0.1 --port 8000
```

Дождитесь строки:

```text
Uvicorn running on http://127.0.0.1:8000
```

После этого откройте в браузере адрес:

```text
http://127.0.0.1:8000
```

По умолчанию откроется вкладка **Обработка**.

Окно PowerShell с запущенным приложением нельзя закрывать до окончания работы.

## Как пользоваться

### Собрать товары

На вкладке **Обработка**:

1. Введите поисковый запрос, например `makita`.
2. Не добавляйте к запросу `scrolling||` — интерфейс сделает это сам.
3. Нажмите **Запустить и скачать Excel**.
4. Не закрывайте специальное окно Chrome и вкладку Megamarket.
5. После завершения браузер автоматически скачает Excel-файл.

Сбор может занимать продолжительное время. Пока отображается сообщение
«Идёт сбор», не запускайте эту же задачу повторно.

Если Megamarket показывает капчу, пройдите её вручную в специальном окне
Chrome и дождитесь продолжения работы.

### Проверить продавцов из Excel

На вкладке **Обработка** в блоке «Проверить продавцов»:

1. Нажмите **Выберите Excel-файл** и укажите файл `.xlsx`.
2. Укажите количество продавцов для проверки. Изначально установлено 4.
3. Нажмите **Проверить и скачать файл**.

Программа добавит в базу новых продавцов из файла, проверит указанное количество
продавцов и скачает обработанный Excel с тем же именем.

Ссылка на продавца попадёт в скачанный файл только при статусе «Корректный».
Если ссылка ещё не проверена или признана неправильной, ячейка останется
пустой.

Исходный файл на компьютере программа не изменяет. Если файл с таким именем уже
есть в папке загрузок, браузер может добавить к имени номер.

### Проверить продавцов без Excel

Файл прикреплять необязательно. Если нажать **Проверить продавцов** без файла,
программа возьмёт из базы указанное количество продавцов со статусом
«На проверке».

В этом случае Excel не скачивается — изменяются только данные в базе.

### Работать со списком продавцов

На вкладке **Продавцы** можно:

- посмотреть количество продавцов каждого статуса;
- отфильтровать список по статусу;
- найти продавца по имени, ID или ИНН;
- открыть страницу магазина;
- изменить данные отдельного продавца;
- выбрать несколько продавцов и одновременно изменить их статус;
- листать список по 10 продавцов на странице.

Статусы означают:

- **Корректный** — ссылка открывает нужного продавца;
- **На проверке** — результат пока неизвестен или сайт не ответил;
- **Некорректный** — страница не существует либо открывает другого продавца.

После автоматической проверки нажмите **Обновить** на вкладке «Продавцы», чтобы
увидеть актуальные данные.

## Как завершить работу

1. Дождитесь окончания текущей задачи.
2. В окне PowerShell с запущенным приложением нажмите `Ctrl+C`.
3. Закройте специальное окно Chrome.

## Следующие запуски

После первоначальной настройки достаточно:

1. открыть PowerShell в папке проекта;
2. запустить специальное окно Chrome двумя командами из шага 4;
3. в другом PowerShell запустить приложение командой из шага 5;
4. открыть `http://127.0.0.1:8000`.

Повторно устанавливать `uv`, выполнять `uv sync` или копировать профиль Chrome
не нужно.

## Если что-то не работает

### Команда uv не найдена

Закройте PowerShell и откройте его заново. Если это не помогло, повторите
установку `uv` из шага 3.

### Не открывается интерфейс

Проверьте, что PowerShell с приложением не закрыт и в нём есть строка
`Uvicorn running`. Затем снова откройте `http://127.0.0.1:8000`.

Также проверьте наличие файла:

```text
frontend\dist\index.html
```

Если его нет, npm устанавливать не нужно. Запросите у администратора полный
комплект проекта с готовой папкой `frontend/dist`.

### Программа не подключается к Chrome

Выполните:

```powershell
Invoke-RestMethod http://127.0.0.1:51112/json/version
```

Если команда завершается ошибкой, закройте все окна Chrome и снова выполните
команды запуска рабочего окна из шага 4.

Если проверка Chrome проходит, а приложение всё равно не подключается, сообщите
администратору: в `.env` должен быть указан тот же порт `51112`.

### Ошибка подключения к базе данных

Проверьте интернет, корпоративную сеть и VPN. Не изменяйте настройки базы
самостоятельно. Передайте администратору текст ошибки из PowerShell.

### Порт 8000 уже занят

Закройте ранее запущенное окно приложения. Если найти его не удалось, запустите
программу на другом порту:

```powershell
uv run uvicorn megamarket.api.app:app --host 127.0.0.1 --port 8001
```

После этого откройте `http://127.0.0.1:8001`.

### Сайт временно ограничил работу

Посмотрите специальное окно Chrome. Пройдите капчу или дождитесь снятия
ограничения.

Чтобы экстренно остановить текущий сбор, закройте вкладку Megamarket, которую
открыла программа. Не закрывайте PowerShell, пока процесс не завершится.

## Обновление программы

После получения новой версии проекта выполните в его папке:

```powershell
uv sync
```

После этого запускайте программу обычным способом. Node.js и npm для обновления
готового интерфейса не требуются.
